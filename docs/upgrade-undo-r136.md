# Upgrade Undo для IX-Ray r1.3.6 (исходный кандидат)

Статус: проверено применение патча к исходникам оригинального r1.3.6; Windows CI для проверки компиляции: https://github.com/SleepDirt67/ipb/actions/runs/43143671940. Работа в игре и корректность сохранений ещё не проверены.

## Функция

Правая кнопка мыши по уже установленному улучшению в дереве у техника -> подтверждение -> снять улучшение.

- Удаляется выбранная модификация и дочерние ступени без требуемых родительских улучшений.
- Независимые ветки остаются.
- По-прежнему действуют обычные ограничения и предварительные условия.
- Стоимость установленного улучшения не возвращается.
- Для брони и шлемов параметры пересчитываются сразу.
- Для оружия требуется сохранить и заново загрузить игру. До загрузки повторная модернизация именно этого предмета недоступна.
- Базовые заводские улучшения уникального оружия должны оставаться установленными.

## Исходный код

Скрипт apply_upgrade_undo.py изменяет шесть файлов C++:

https://github.com/SleepDirt67/ipb/blob/feature/upgrade-undo-r136/mods/UpgradeUndo/apply_upgrade_undo.py

Применение: python mods/UpgradeUndo/apply_upgrade_undo.py ixray после получения исходников ixray-team/ixray-1.6-stcop версии r1.3.6.

Это не Lua-мод: движок не умеет удалять установленный апгрейд с пересчётом характеристик. Исходный патч должен быть скомпилирован вместе с другими используемыми изменениями.

## Ограничение

Нельзя заменять DLL из тестового workflow в рабочей сборке без проверки на отдельной копии: изолированный CI компилирует upstream r1.3.6 + Upgrade Undo и не включает другие пользовательские исправления управления, HUD и производительности. Для рабочей сборки сливайте исходный патч в исходники, из которых она сделана.

Нужна отдельная проверка в игре, включая сохранение/загрузку, откат родительской и дочерних модификаций, оружие с боеприпасами и уникальные предметы.
